# M.T.A. 終幕設計 v3「信頼RTA」

作成日：2026-10-04
変更の要点：PC1の目標を「自分を指名させる」から「**ジョー・カーを犯人に選ばせる**」に変える。証拠はジョーの無実をはっきり示す。一真の武器は、今夜三人から集めた**信頼だけ**。再解釈パートは独立させず、投票後の終幕（ED）に統合する。

---

## 1. コンセプトとの対応

| コンセプト | v3での形 |

## 2. 世界観（EDで語るのはこれだけ）

1. **この夜は、神経衰弱。** 外れた札は裏返り、記憶だけが残って、もう一度めくり直す。
2. **裏返していたのは一真。** 結末を見て「違う」と思うたび、秒針が止まり、夜は17:30のラウンジへ戻る。
3. **一真の望みは一つ。四人で、普通に帰ること。**（PC1 HO-Aの「今回の旅行を普通に終わらせたい」）
4. **最初の夜、四季は帰ってこなかった。** 殺人は一件もない。逃げた三人が事故で死に、朝陽は遺書を書いて薬を飲み、倒れた朝陽を助けようと一人で嵐へ出た四季が死んだ。8・7・6・5・4。
5. **誰かを救えば、別の誰かが死ぬ。** 朝陽が助かる夜には、四季が死んだ。何百回目かで、四人が揃って朝を迎える手順が一つだけ見つかった。十一人のうち、六人が死ぬ手順。
6. **それでも夜は終わらなかった。** 三人が書いた名前が、いつも「違った」から。開二の夜、美津の夜、四季の夜、一真自身の夜。
7. **朝まで生きているのは、四人とジョーだけ。** まだ書かれていない名前は、ジョー・カーしかない。

### なぜジョーでなければならないのか

- **論理**：四人で帰るには、犯人は四人以外でなければならない。生き残っている四人以外は、ジョーだけ。四人の名前は過去の夜に全部書かれ、どれも終わらなかった。
- **一真の信仰**：ジョーの言葉「お前の望む結果にならないと、きっと終わらない」。一真は、夜を終わらせるのは**三人の選択（投票）**だと信じている。だから証拠は要らない。必要なのは三人の信頼だけ。
- **残酷さ**：ジョーは、一真がループを打ち明けた**ただ一人の相手**だった。しかも記憶が続かないので、自分の無実すら覚えていられない。一真は、言葉をくれた男にババ（ジョーカー）を引かせる。

### オチ（裏返る点）

- 夜を終わらせていなかったのは、投票ではなく一真自身だった。三人が正しく一真を選んだ夜もあった。それでも一真は「違う」と思って巻き戻した。
- ジョーの言葉は出口の条件ではなく、「思い通りになるまで書き直すお前がいる限り、終わらない」という指摘だった。
- 一真が三人のために作った「最良の朝」は、三人の誰も頼んでいない朝だった。
  - 四季：「私は、そんな朝を頼んでない」

## 3. 終幕の分岐（投票結果で決まる）

| 分岐 | 条件 | 中身 | 締めの一文 |
|---|---|---|---|
| **J：信頼RTA成功** | 最多票がジョー | 一真は「違う」と思わず、夜が明ける。ジョーは自分の無実を覚えていない。四人は揃って帰る。プレイヤーには真相を語り、終幕後に「誰にも読まれなかった手帳」を配る | 信頼は、RTAできる。 |
| **K：一真が捕まる（正解）** | 最多票が一真 | 一真が「違う」と言いかけたところで、四季がジョーの手帳を持ってくる。手帳を読み、記憶カードを朗読し、真相を語り、走られた側の感想を聞く。最後にPC1が**完走か再走か**を選ぶ | 完走：信頼は、RTAできない。／再走：信頼RTA、再走。 |
| **X：揃わない** | 上記以外 | 一真「まだ、揃わないか」。リセットされる。終幕後に手帳と真相を配る | まだ、揃わない。 |

- 真のエンディングは **K → 完走**（「一回目の朝」）。
- Kの卓で、PC2～4の誰かがジョーに投票していた場合、その人に専用の台詞を用意した。「証拠より、お前を取った」。信頼された側が一番傷つく、というコンセプトの核になる。

## 5. 本編への影響（最小限）

v3の利点は、**事件の真相・物証・40枚の構成を変えずに済む**こと。証拠はもともと一真を指しているので、足すのはジョーの無実を示す材料だけでよい。

| 対象 | 変更 |
|---|---|
| PC1 HO-B | 目的・「なぜジョーか」・最終議論での振る舞いを差し替え、17:41の会釈を追加する（改稿案は04） |
| C35 | 「ジョーの部屋の扉は22:10に閉じ、朝まで開いていない」を追記する。8・7・6・5を配置した時刻にジョーは眠っていた、という決め手になる |
| J01～J06の公開時 | ジョーの素性を一言添える（校正者、記憶が続かないこと、22:10に部屋へ戻ったこと）。一真が「覚えていないだけだ」と押す材料にも、プレイヤーが疑う材料にもなる |
| 読み合わせ1 | ジョーの存在と会釈を追加する（v2と同じ） |
| 読み合わせ6 | 3分岐の終幕に差し替える（01） |
| 最終推理（解説） | 「一真対ジョー」の判別点を追加する：22:10以降の扉、8・7・6・5を一真が預かっていたこと、21:54の二人の目撃、崖の痕跡、Jメモの濃紺の袖 |
| 最終議論での過去投票の必須公開 | **廃止。** ループを明かすかどうかは、PC1が自分で選ぶ |

### 難易度について

- 証拠は明らかに一真を指すので、**J分岐（信頼RTA成功）はまれ**になる。それで構わない。説得の役は、勝ちにくいほどドラマになる。
- PC1の見せ場は三つある：①今夜、三人の目標を叶えて信頼を集めること ②最後の説得 ③K分岐での完走／再走の選択。
- 調整のつまみ（任意）：PC1の目的達成を「ジョーに入れた人数」で部分評価にする。1票でも入れば、信頼RTAの部分達成とする。

## 6. 作者の判断が要る点

| 項目 | 内容 |
|---|---|
| 最初の夜で四季が死ぬ | 新しい設定。第1の主要ループの「23:11、救助へ向かった四季が死亡」と同じ形にした |
| 朝陽を殺す理由 | 朝陽に助かる見込みがあると、四季が助けを呼びに一人で嵐へ出る。だから一真は、朝陽が確実に死ぬ薬に替え、四人をラウンジに集めた。本編の事実（19:35の薬交換、23:03の服用、同席）は変えない |
| 十文字・九条を殺す理由 | 作者用に、主要ループと結びつけて整理する。九条が20:30に送信すると八神が早く逃げる（第1の主要ループ）。十文字が朝陽を連れ出すと四季が事故で死ぬ（第16の主要ループ）。ED本文では「十一人のうち六人が死ぬ手順」とだけ言う |
| 投票の決め方 | 最多票で分岐する（旧ED-Aは全会一致だった）。全会一致を求めるなら条件を差し替える |
| 再走の終幕 | 一真は今度はジョーに会釈しない。記録を残させないためで、走者が乱数を調整したことになる。後味は最も悪い |
