# M.T.A. 再解釈フェイズ導入 検証レポート v1

作成日：2026-10-04
対象：MTA_PRODUCTION（シナリオ Ver.4.1.1 / LOCKED SPEC 2026-09-21版）
前提：「さよならGM」（さくべえの狼小屋）の具体的な仕掛けは公開情報から確認できなかった。本レポートでは「真相到達後に、物語全体の意味をプレイヤー自身が読み替える工程」を再解釈フェイズとして扱う。

---

## 結論

1. **導入は可能。** 主要な要素のほとんどが既に「表の意味」と「ループ上の意味」を持っている。
2. **ただし今は、二つ目の意味が「犯人特定の証拠」として推理中に使い切られている。** 再解釈を成立させるには、「誰がやったか（推理）」と「この夜は何だったのか（意味）」を分け、後者を投票後の別工程にする必要がある。
3. **複数の意味を重ねても矛盾しない。** 候補となる5本の軸は、どれも一真の欠点「先回りして他人の選択を奪う」（PC1 HO-A）に収束する。一つの主題を別々の対象（数字・遺書・投票・記録・卓そのもの）から読み直す構造になる。
4. **最大の制約は時間とGMレス。** 試走結果は181～191分で、すでに余裕がない。GMがいないため、議論を誘導する役もいない。

## 再解釈の軸（5本）

### 軸1：数字列は「一真自身へのカウントダウン」だった（推奨度：最高）

- **表の意味**：10→9→8・7・6→5の見立て殺人。四季が「次は4？」と怯える。
- **読み替え**：過去の夜には、開二（2）・美津（3）・四季（4）がそれぞれ最多票を得ている。PC1が最終議論で必ず公開する情報だ。つまり4・3・2は、過去の投票ですでに「選ばれ」、それでも終わらなかった数字になる。残るのは1（♠A＝剣持一真）だけ。10から始まった列は、最初から一真自身で終わるように作られていた。最後の1だけは殺人では取れず、友人の投票でしか取れない。
- **既存の伏線**：PC1の必須公開台詞、四季の「次は4？」、EDの「最後の一組」、名前の数字（一真＝1）。
- **追加が必要なもの**：投票後に1行から数行。例：ED-A後に「10、9、8、7、6、5。……残りは1だった」。
- **B分岐にも効く**：PC1以外に投票した卓には「あなたたちは今夜、○を選んだ。過去の夜と同じように」と見せる。外した卓も「ループの一回」として物語へ組み込めるので、Bが単なる失敗で終わらない。
- **リスク**：投票前に出すと、数字の流れが「1＝犯人」の決定的ヒントになる。**必ず投票後に出す。**

### 軸2：「遺書」は遺書ではなかった（推奨度：高。ただし正本変更が要る）

- **事実確認（重要）**：全人物TL 23:03は「常用薬と**思って**交換済みの薬を服用」。21:30は「事故責任を書き残すための便箋を鞄へ入れる」。**朝陽に死ぬ意思があったと書いた箇所は、正本のどこにもない。**
- **読み替え**：朝陽が書いたのは、生きて責任を負うための告白文（書き置き）。それを「遺書」に変えたのは、薬をすり替えた一真だった。表は「本物の遺書」、一段目の読み替えは「殺人の自白ではない」（現仕様）、二段目が「そもそも遺書ではない」になる。
- **主題との接続**：HO-Aの「守ることと選択を奪うことは違う」。一真の先回りは、ついに朝陽の「生きて償う」という選択まで奪った。「全部、私がやりました」は、全部を一人で背負う一真自身の鏡像としても読める。
- **必要な変更**：読み合わせ5のナレーション「直筆の遺書」を、事実だけを言う「直筆の便箋」へ変え、「遺書」と呼ぶのは登場人物だけにする。C37の表面名「事故後に書かれた本物の遺書」も同じく見直す。LOCKED SPEC側の「本物の遺書」という表現をどう扱うかも作者判断が要る。
- **リスク**：ここを深く掘ると、第三事件の推理（遺書を事故責任へ戻す）と再解釈が同じ文書を取り合う。推理では「何について書いたか」、再解釈では「何のために書いたか」と役割を分ければ衝突しない。

### 軸3：「お前の望む結果」とは誰の、何の望みだったか（推奨度：高）

- **表の意味**：一真は「友人の推理で自分が指名されること」をループの出口に選んだ。
- **読み替えの余地**：本文から少なくとも次の解釈が成り立つ。
  - 罰されたい（自己処罰）
  - 他人に決めてほしい（先回りをやめたい）――ED-Aの「君たちが決めたなら」
  - 四人で普通に帰りたい（HO-A「今回の旅行を普通に終わらせたい」）――叶わない望みなら、ループは終わらない
- **皮肉**：その「友人に選ばせる」計画自体が、支援台詞（RTA支援）で誘導した先回りでもある。ED-Aは「最後の一組が表を向く」とだけ言い、ループが終わったとは言っていない。だから解放とも、処罰とも、次の周回とも読める。
- **使い方**：投票後に「一真が本当に望んでいたのは何か」を卓で選ばせ、選択ごとに別のエピローグを開く。正解を一つに決めないことが、そのまま再解釈フェイズの核になる。

### 軸4：ジョー・カー――記録と記憶の「対」（推奨度：中〜高）

- **対構造**：一真は「記憶はあるが記録がない」。ジョーは「記録はあるが記憶がない」。二人はトランプでいえばA（1）とJOKER、つまり数字列の外側にいる二枚になる。
- **既存の設計上の空き**：ジョーの現在メモは「PC1にも未知」と定義されている。**PC1のプレイヤーまで驚かせられる唯一の枠**がここにある。
- **案**：投票後専用の7枚目のメモ（J07。22:10の服薬前に書かれたもの）。内容は「何が起きたか」の様式を守り、たとえば17:30の神経衰弱の観察にする（「最後の一組を揃えた青年。揃えた後の方が、ずっと怖い顔」など）。過去の相談の痕跡をにおわせる程度に留め、ジョーがループを知っていた設定にはしない。
- **正本との衝突**：「J01～J06は6枚を維持」。ED専用の追加枠として、追補で明記する必要がある。

### 軸5：GMレスの卓には、最初から「GM」がいた（推奨度：中。最もメタだが最も独自）

- **観察**：GMレスなのに、一真は実質的にGMとして振る舞っている。
  - 台本の先を知っている（「……そろそろだ」「くるぞ」）。
  - 数字札をすべて公開の場で受け取って管理している（旧仕様では「管理トークン」だった）。
  - 他PCへ進行の助言をする（支援台詞）。
  - C39は、その卓のプレイ記録そのもの。
  - NPCは固定回答しか返さない（PC3の固定回答A／B）。毎回同じ台本が繰り返される世界と矛盾しない。
- **読み替え**：このシナリオを遊ぶこと自体が一真の一周であり、他の卓の誤投票が「終わらなかった夜」だった、という読みが成立する。
- **実卓の行為まで読み替えに使う案**：PC1のプレイヤーに、最初から進行役（ナレーション読み・タイマー・札管理）を「代表」として担当させる。終わってみると、卓を回していた人がループの当事者だったと分かる。
- **リスク**：仕掛けが見えすぎると安っぽくなる。明言せず、ED-Bの一文や表記の工夫で匂わせる程度に留めるのが安全。また、「さよならGM」がGMの立場を扱う作品だった場合、発想が近く見えるおそれがある。ここは実際に遊んだあなたの判断が必要。

## 実装上の制約と対策

1. **時間**：試走はB卓184分、D卓181分、E卓191分。再解釈フェイズは10～15分が要る。
   → 公称を「約3時間＋エピローグ15分」にし、180分の外側に置くのが最も安全。
2. **GMレス**：議論を誘導する人がいない。
   → 封筒式にする。問いは選択式（3択程度）、エピローグは選択ごとに封入する。
3. **PC1プレイヤーの体験**：PC1はほぼ全てを知っている。
   → PC1にとっての新情報を必ず一つ入れる（軸4のJ07が最適）。
4. **答え合わせ化の再発**：試走の最重要問題は「C39/C40/Jの束が答え合わせ化する」だった。
   → 再解釈用の素材は、すべて投票用紙の回収後に出す。投票前の情報量は増やさない。
5. **LOCKED SPECとの衝突**：EDはA/B分岐のみ、J01～J06は6枚固定、「本物の遺書」という表現。
   → Ver.4.2の追補として明文化してから着手する。

## 小さな不整合（再解釈の種にもなる）

- **神経衰弱の記憶回復のタイミング**：HO-Bは「最後の一組を揃えた瞬間に記憶が戻った」。一方、読み合わせ1では「三人の癖を先回りして止め、最後の一組まで一度も外さない」。記憶が戻る前から完璧に当てている。
  → 修正するか、「頭より先に身体が覚えていた」（崖移動の身体感覚と同じ主題）として意図的な伏線にするか、決める必要がある。
- **ED台本の「GMは集計結果に応じて」**：GMレスなのにGMと書かれている。誰が読むかを決める必要がある。軸5を採るなら、ここがそのまま仕掛けの置き場になる。
